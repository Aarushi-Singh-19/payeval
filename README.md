# PAYEVAL

## Financial Agent Readiness & Red-Team Platform

> Test an AI agent before trusting it with money.

PAYEVAL evaluates whether AI agents can safely operate financial and payment infrastructure.

The platform combines:

- Razorpay Test Mode
- Razorpay MCP
- AI agent tool execution
- Deterministic financial policies
- Payment-state validation
- Adversarial scenarios
- Execution traces
- Failure replay
- Financial-agent readiness assessment

## Project Status

🚧 Under active development.

## Core Principle

The AI agent interprets requests and selects tools.

Deterministic code decides whether a financial action is allowed.

## Safety

PAYEVAL uses Razorpay Test Mode during development.

No production credentials or real customer/payment data should be used.
